About Me

My name is Fact Bwalya and I am a first-year student passionate about technology and the way websites are built. I grew up curious about how the internet works behind the scenes, and that curiosity is what led me to study web development. Outside of class I enjoy listening to music, playing chess, and spending quality time with my girlfriend. Chess has taught me to think ahead and solve problems calmly, which I find very useful when debugging code. I am taking this course because I want to build my own portfolio, learn HTML, CSS, and JavaScript properly, and eventually work as a front-end developer. So far I have learned how to structure a page with semantic HTML, and I am excited to keep improving my styling skills with CSS this semester.

My Projects & Skills

Here are some of the things I have learned and built so far this semester.

Semantic HTML Portfolio

Built a full personal website using header, nav, main, section and footer with proper heading hierarchy.

Learned to use figure, figcaption, table, form, and video/audio elements — all with accessibility in mind (alt text, labels, transcripts).

Responsive CSS Layout

Styled a multi-section site with a coherent colour palette and a mobile-friendly layout.

Used Flexbox, Grid, media queries, hover and focus states, and demonstrated the box model with padding, margin and borders.

Interactive JavaScript

Added interactive features — form validation, gallery viewer, theme switch, and a calculator.

Practised events, DOM manipulation, arrays, functions, and using textContent for safe display of user input.

My Learning Plan

Here are the realistic steps I will take to improve my web skills:

  1. Complete one HTML and CSS lesson per week on MDN Web Docs.
  2. Rebuild one simple website from scratch every two weeks for practice.
  3. Start learning JavaScript basics by month two, focusing on DOM manipulation.
  4. Publish all my small projects to GitHub so I can track my progress.
